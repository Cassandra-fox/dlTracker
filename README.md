# DL Price Tracker

**在 DLsite 浏览作品时查看历史最低价，把想买的作品整理成自己的本地追踪清单。**

DL Price Tracker（DLTracker）是一款适用于 Chrome 和 Edge 的浏览器扩展。你可以直接在作品页、收藏列表查看史低，也可以导入收藏，集中更新价格、记录购买计划并导出CSV表格清单。

## 功能与亮点

| 功能         | 能帮你做什么                                                            |
| ------------ | ----------------------------------------------------------------------- |
| 页面直接查价 | 在作品页和收藏列表显示历史最低价，有数据时可跳转 DLwatcher 查看价格趋势 |
| 独立追踪清单 | 从收藏页追加作品；在 DLsite 取消收藏，不会丢失本地追踪记录              |
| 灵活更新     | 更新单个作品、勾选的作品或全部追踪作品，并查看成功、失败和无数据数量    |
| 保留已知史低 | 更新失败不清空旧价格；新返回的史低更高时，保留本地已记录的更低价格      |
| 作品备注     | 为作品记录购买计划、阅读进度或个人评价，支持最多 1000 字符              |
| CSV 导出     | 导出追踪作品的信息、价格、状态、备注和最近成功更新时间                  |
| 全频道支持   | 支持 RJ、BJ、VJ 编号及不同频道（comipo漫画专区除外）的作品链接          |
| 本地保存     | 追踪清单和备注保存在当前浏览器中，无需额外注册插件账号                  |

批量更新时，单个作品失败不会中止其他作品。你可以在任务结束后重试失败项；如果浏览器关闭或任务意外中断，已经保存的结果仍会保留。

## 安装

提供以下两种安装方式，均通过 Chrome / Edge 的开发者模式加载。

### 方式一：从 Releases 下载 ZIP（推荐）

无需安装 Node.js，也不需要自行构建。

1. 打开本项目的 [Releases 页面](https://github.com/Cassandra-fox/dlTracker/releases)，在对应版本的 **Assets** 中下载扩展 ZIP，例如 `dl-price-tracker-v2.0.0.zip`。请选择扩展压缩包，而不是 GitHub 自动生成的 `Source code (zip)`。
2. 将 ZIP 解压到一个固定文件夹，之后保留该文件夹，不要删除或移动。
3. 打开扩展管理页：Chrome 为 `chrome://extensions`，Edge 为 `edge://extensions`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压后的文件夹。
5. 刷新已打开的 DLsite 页面，即可开始使用。

### 方式二：从源码构建

适合希望自行构建或修改代码的用户，需要 Node.js 22.20 或更新的兼容版本。

1. 克隆本仓库，或下载并解压源码。
2. 在项目根目录打开终端，安装依赖并构建：

   ```sh
   npm ci
   npm run build
   ```

3. 构建完成后，打开 `chrome://extensions` 或 `edge://extensions`，开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择项目中生成的 **`dist` 文件夹**。
5. 刷新已打开的 DLsite 页面，即可开始使用。

建议将插件固定到浏览器工具栏，方便打开管理页。

更新插件文件后，先在扩展管理页点击“重新加载”，再刷新 DLsite 页面和已打开的插件管理页。

## 开始使用

### 浏览时查看史低

打开 DLsite 作品页，插件会在价格区域显示历史最低价；收藏列表中也会显示对应作品的史低信息。

**查价不需要先收藏或导入作品。** 如果尚未取得史低且请求失败，刷新当前页面即可重新尝试。成功取得的普通浏览记录会缓存 24 小时，减少重复请求。

价格来自 DLwatcher，页面展示位置取决于 DLsite 的页面结构。能够识别作品链接，不代表上游一定收录了该作品的价格。

### 导入收藏，建立追踪清单

1. 打开 DLsite 收藏页。
2. 点击“导入当前页”。
3. 等待导入结果，查看新加入数量及价格获取进度。
4. 如果收藏有多页，翻到下一页，再次点击导入进行追加。

导入**只包含当前页的收藏列表**，不会自动读取其他分页，也不会把推荐区域的作品加入清单。

- 支持每页展示 30、50 或 100 个作品。
- 重复导入会去重，已有作品、备注和其他追踪记录都会保留。
- 已有价格可直接复用，缺失的价格会尝试获取。
- 单次最多导入 300 个不同作品，超过时可继续分批导入；本地追踪总数不设人为上限。

### 管理价格与备注

点击工具栏中的插件图标，再选择“打开管理页”。

| 操作         | 使用方式                                                   |
| ------------ | ---------------------------------------------------------- |
| 更新一个作品 | 点击该行的“更新”                                           |
| 批量更新     | 勾选作品后点击“更新选中项”，也可以全选当前列表             |
| 更新整个清单 | 点击“更新全部”，或使用插件弹窗中的“更新全部追踪价格”       |
| 重试失败作品 | 本次更新结束后，点击可用的“重试失败项”                     |
| 添加备注     | 点击“编辑备注”，输入内容后保存；清空内容并保存即可删除备注 |
| 删除追踪     | 勾选作品，点击“删除选中项”并确认                           |
| 导出清单     | 点击“导出 CSV”，导出全部本地追踪作品                       |

“刷新列表”只重新读取本地记录；需要向 DLwatcher 查询新数据时，请使用“更新”按钮。

已有史低的追踪作品不会因日常浏览而自动更新。你可以自行决定何时查价，价格更新和重复导入都不会覆盖备注。尚无价格的作品也会出现在管理页中，方便稍后重试。

## 清单和数据如何保留？

**本地追踪与 DLsite 收藏互相独立。** 取消网站收藏不会移除本地记录，删除本地追踪也不会改变网站收藏。

删除本地追踪时，该作品的备注会一并删除；已有价格可能继续作为普通浏览缓存保留。以后可以重新导入作品，但已删除的备注不会自动恢复。

追踪记录不会因为普通缓存的 24 小时期限而被清理。当前版本没有云同步，换浏览器或设备不会自动同步清单；卸载扩展或清除扩展数据前，可先导出 CSV 留存。CSV 用于查看和保存清单，当前不支持从 CSV 恢复导入。

## 常见问题

### 为什么有些作品没有史低？

DLwatcher 可能尚未提供对应作品的价格数据，也可能暂时出现网络、超时或服务端错误。插件会尽量显示具体原因：

- **HTTP 404**：本次请求未取得该作品的价格文件，一般出现在当天发售的新作品上，DLwatcher暂未记录该作品的史低数据，不代表该作品永久不受支持。
- **网络错误 / 请求超时**：网络问题，可以刷新作品页重试。
- **请求受限**：请稍后再试，频繁刷新不会绕过上游限流。
- **暂无有效史低数据**：接口已响应，但未提供有效价格，与请求失败不同，此失败原因来自于DLwatcher数据无效，无法通过刷新页面解决，请勿短时内频繁重复刷新尝试。

尚无史低且请求失败时，刷新作品页即可重试。如果上游仍未提供数据，重试后也可能继续显示相同提示。

### 为什么插件显示的史低与上游不一样？

插件会保留本地已经记录过的更低价格，不因上游后来返回更高数值而上调。历史最低价也不代表当前购买价，请以 DLsite 结算页面为准。

### 导入提示页面与后台版本不一致怎么办？

先在扩展管理页重新加载 DLTracker，再刷新 DLsite 收藏页后重试。只刷新网页可能没有更新插件后台。

### 更新中途关闭浏览器会怎样？

已保存的结果会保留，未完成的任务不会自动续跑。下次打开管理页后，可以主动重新更新。

### 插件会上传备注吗？

备注和追踪清单保存在当前浏览器的扩展本地存储中，不做云同步。查价时会将对应的作品编号发送给 [DLwatcher](https://dlwatcher.com/)；备注不会随查价请求上传。

## 开发与检查

项目使用 TypeScript、Manifest V3、Vite、IndexedDB（idb）、dayjs 和原生 DOM。开发检查命令：

```sh
npm run typecheck
npm run lint
npm test
```

生产包的浏览器验收脚本见 [scripts/browser-smoke.mjs](scripts/browser-smoke.mjs)，使用独立测试配置，不读取个人浏览器数据。

> 本版会保留并升级已有本地数据库。升级后的数据库不能直接由仅支持旧数据库版本的程序打开；回退代码前请注意版本兼容性。
